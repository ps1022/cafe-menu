# 카페 메뉴

손님용 메뉴판 페이지와 **음성으로** 메뉴 추가·삭제·가격 변경이 가능한 관리자 페이지입니다.

## 1. Supabase에서 테이블 만들기 (한 번만 하면 됨)

1. [Supabase](https://supabase.com)에 로그인하고 사용 중인 프로젝트를 엽니다.
2. 왼쪽 메뉴에서 **SQL Editor**를 클릭합니다.
3. **New query**로 새 쿼리를 만든 뒤, 아래 파일 내용을 **전부 복사**해서 붙여넣습니다.  
   파일 위치: `supabase/migrations/001_menu.sql`
4. **Run** 버튼을 눌러 실행합니다.  
   → `categories` 테이블, `menu_items` 테이블, 샘플 메뉴(커피/라떼/프라페)가 생성됩니다.

## 2. 프로젝트 실행

터미널에서 프로젝트 폴더로 이동한 뒤:

```bash
npm run dev
```

브라우저에서 **http://localhost:3000** 으로 접속합니다.

- **메뉴판**: 첫 화면에서 카테고리별 메뉴 목록을 볼 수 있습니다.
- **관리자**: 화면 하단 "관리자 →" 링크 또는 **http://localhost:3000/admin** 으로 이동합니다.

## 3. 관리자 페이지에서 음성 사용 방법

1. **http://localhost:3000/admin** 에서 **"음성 켜기"** 버튼을 누릅니다.
2. 마이크 사용 허용을 요청하면 **허용**을 선택합니다.
3. 아래처럼 말하면 자동으로 인식됩니다.

| 하고 싶은 것 | 말하기 예시 |
|-------------|-------------|
| 메뉴 삭제 | "에스프레소 삭제" / "삭제 에스프레소" |
| 가격 변경 | "카페라떼 가격 4.5" / "가격 카페라떼 4.5" |
| 메뉴 추가 | "추가 커피 디카페인 4.0" / "커피 디카페인 4.0 추가" |

- **추가**할 때는 반드시 **카테고리(커피/라떼/프라페)** + **메뉴 이름** + **가격**을 같이 말해야 합니다.
- 가격은 **숫자만** 말하면 됩니다 (예: "4.5", "5").

## 환경 변수

`.env.local` 에 다음이 설정되어 있어야 합니다 (이미 있으면 수정하지 않아도 됩니다).

- `NEXT_PUBLIC_SUPABASE_URL` : Supabase 프로젝트 URL
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` : Supabase anon public key

Supabase 대시보드 → Project Settings → API 에서 확인할 수 있습니다.
